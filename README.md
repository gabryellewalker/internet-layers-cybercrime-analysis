# Internet Layers & Cybercrime Analysis

## Project Overview

This project analyzes the three commonly discussed layers of the internet: the surface web, deep web, and dark web. It examines how each layer functions, how cybercriminals exploit these environments, and the cybersecurity risks associated with activities such as phishing, ransomware, credential theft, fraud, and data breaches.

The project also examines how cybersecurity professionals and investigators can use an understanding of these environments to identify threats, recognize criminal activity, and support digital investigations.

## Objectives

- Compare the surface web, deep web, and dark web.
- Identify common cybercriminal activities associated with each layer.
- Analyze how cybercriminals exploit legitimate online services and systems.
- Examine phishing, ransomware, data theft, fraud, and other cyber threats.
- Explore the role of the dark web in cybercrime.
- Identify considerations for cybersecurity investigations and digital evidence.

## Internet Layers

| Layer | Description | Examples of Cybercrime |
|---|---|---|
| Surface Web | Publicly accessible content indexed by traditional search engines. | Phishing, scams, malware distribution, identity theft |
| Deep Web | Content that is not indexed by search engines and typically requires authentication or authorization. | Unauthorized access, database attacks, data theft, ransomware |
| Dark Web | Hidden internet services that require specialized software or configurations to access. | Stolen-data marketplaces, criminal communications, Ransomware-as-a-Service |

## Cybersecurity Analysis

### Surface Web

The surface web contains publicly accessible websites and services such as social media platforms, news websites, business websites, and online marketplaces.

Cybercriminals can exploit these platforms through phishing websites, fraudulent advertisements, social engineering, malware distribution, and impersonation attacks.

### Deep Web

The deep web includes legitimate private or restricted information such as online banking portals, healthcare portals, corporate systems, university learning platforms, and private databases.

Although the deep web is not inherently malicious, cybercriminals may attempt to gain unauthorized access to these systems to steal sensitive information or deploy ransomware.

### Dark Web

The dark web consists of intentionally hidden services that require specialized access. Although it can support legitimate privacy and anonymous communication, criminal organizations have also used dark-web services to communicate, distribute stolen information, and facilitate cybercrime.

One significant example is Ransomware-as-a-Service (RaaS), where ransomware developers provide tools or services to affiliates who conduct attacks against organizations.
